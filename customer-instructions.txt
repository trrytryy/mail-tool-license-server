Mail Pro Tool activation instructions for customers:

1. Download and install the latest Mail Pro Tool setup.
2. Open the app - it will show a license status screen.
3. Copy the displayed Machine ID and send it to the seller/admin.
4. Admin will activate your license using the Machine ID.
5. Close and reopen the app to check activation status.
6. If activated, you can use all features of the tool.

Important:
- Use this latest version of the tool only.
- Delete the old version before installing the new one.
- The app connects to: https://mail-tool-license-server-tau.vercel.app
- If you see "Chưa kích hoạt", send Machine ID to admin for activation.
